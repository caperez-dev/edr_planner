Write a complete, single-file HTML application named edrplanner.html for an EDR MOP and Application Planner.

Output the entire working application in one single code block without any placeholders, omissions, or multi-part splits. Keep the total file size compact and under 400 lines by writing dense, idiomatic JavaScript and Tailwind utility classes.

Technical Stack:
- Google Fonts Inter, Tailwind CSS via CDN with dark mode enabled.
- SheetJS via cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js for Excel exports.
- Lucide Icons via unpkg.com/lucide@latest for icons.

Layout and UI:
- Top Header: Title EDR MOP & Application Planner, night mode toggle, search bar, expand and collapse buttons, and clear plan button.
- Left Sidebar: Application list with Add App button, search filter, All Applications selector, and app cards with edit and delete buttons.
- Top Banner: Settings button, active application name and last updated label, Import JSON, Export JSON, Export XLSX, Timeline toggle, and Table and Calendar view switcher buttons.
- Dual Workspace: Side-by-side view featuring a 75 percent width table aligned row-for-row with a 25 percent width hourly Gantt timeline with synchronized vertical scrolling.
- Calendar View: Alternate view displaying scheduled tasks on a monthly and weekly grid with milestone filters.
- Reusable Modal: One single dynamic modal dialog reused for cell editing, application attributes, custom settings chips, and confirmation dialogs.

Data and Features:
- Hierarchy: Predefined Failover and Failback phases with standard subphases like Pre Failover, Failover, Testing, and Post Failover.
- Table Columns: Index, App Name, Task, Dependency, Type, Duration, Planned Start, Planned End, Actual Start, Actual End, Owner, Backup, Checker, Comments, and Issues.
- Interactions: Double-click or right-click any task cell to open the editor with searchable team assignees, date pickers, and dropdowns. Right-click header to toggle column visibility. Lock button to freeze columns.
- Storage and Export: Automatically persist all state, apps, custom dropdowns, and theme in browser local storage. Support uploading single MOP files, importing multi-app JSON bundles, exporting portable JSON files, and exporting multi-sheet Excel files.
