### 6. SIDE-BY-SIDE TIMELINE ENGINE (`renderTimeline`)
- **Date Range Calculation**:
  - Extract valid timestamps from all tasks' `start` and `end`.
  - Use `timelineRange.start` and `timelineRange.end` if set by the user; otherwise fall back to auto min/max task dates (capped at 31 days max).
- **Two-Row Sticky Header (`<thead class="sticky top-0 z-20">`)**:
  - **Row 1 (Day Header, `h-7`)**: One `<th colspan="24">` per day. Inside each day header, place a horizontally sticky inner container (`<div class="sticky left-1.5 inline-flex items-center gap-2">`) containing the date string (e.g. `Thu, Nov 6, 2026`) and a **`"Date Range"`** button (`onclick="openTimelineRangeModal(event)"`). This ensures the date and button stay visible as the user scrolls horizontally.
  - **Row 2 (Hour Header, `h-7`)**: 24 narrow columns per day (`w-8 min-w-[32px] max-w-[32px] px-0 text-center font-mono text-[9px] tracking-tighter`) formatted compactly as `12 AM`, `1 AM`, ..., `12 PM`.
- **Body Rows (`h-9`)**:
  - Phase and Sub-Phase rows render empty `h-9` full-colspan cells matching the main table's background colors (no text labels). Clicking them toggles collapse.
  - Task rows render 32px hourly vertical grid lines in the background and an absolutely positioned task bar (`left: ${leftPct}%; width: ${widthPct}%`) with an indigo-to-violet gradient, **slightly curved edges (`rounded-sm`)**, no text label inside the bar, and a native `title` tooltip with app name, task name, planned start/end, and duration.
  - Clicking or double-clicking timeline bars must **not** open any modal.
- On initial render, auto-scroll `#timelineScroll.scrollLeft` to 1 hour before the earliest task timestamp.

### 7. SEPARATED UPLOAD ("ADD APP") VS. "IMPORT JSON" & EXPORTS
- **`openFileModal(mode)`**:
  - `'single'` (triggered by sidebar **`"Add App"`** button): Sets modal title to `"Add Single Application MOP"`, disables multi-file selection (`multiple = false`), and accepts a single app JSON/JS file. If the parsed file contains a multi-app array (`parsed.apps` or array of app objects with `.tasks`), show an `alert('This file contains multiple applications. Please use "Import JSON" instead.')` and abort.
  - `'multi'` (triggered by top banner **`"Import JSON"`** button): Sets modal title to `"Import Multi-App Planner JSON"`, enables `multiple = true`, and imports multi-app exported files (`parsed.apps`, plus restoring `parsed.depOptions` and `parsed.typeOptions` if present) or multiple single-app files.
  - Support both raw `.json` and `.js` files (strip leading `window.xyz =`, `const xyz =`, `export default`, and trailing semicolons before `JSON.parse`).
- **`Export JSON` (`#exportDataBtn`)**:
  - Opens confirmation modal (`"Export portable table file?"`) and downloads `edr-planner-table.json` containing `{ apps: uploadedApps, depOptions, typeOptions, exportedAt: nowStamp() }`.
- **`Export XLSX` (`#exportJsonBtn`)**:
  - Opens confirmation modal (`"Export workbook?"`) and uses `XLSX.utils.json_to_sheet` to generate a multi-sheet `.xlsx` file (`edr-planner-${exportName}.xlsx`), one sheet per application in the active view.

### 8. UNIFIED EDIT MODAL, SETTINGS MODAL & AUTO-TIMESTAMPING
All edits update `app.lastUpdated = nowStamp()` (formatted as `"6 Nov 2026 12:30 PM"`), save to `localStorage`, and re-render.
1. **Settings Modal (`#openSettingsBtn`)**:
   - Modal title: **`"Settings"`**.
   - Displays **Dependencies** (`depOptions`) and **Task Types** (`typeOptions`) as flex-wrapped chips.
   - **Hover-to-Delete**: Each chip has `group` class and a `&times;` button (`opacity-0 group-hover:opacity-100 hover:text-red-500`) that calls `removeDropdownOption(kind, index)` to delete that option immediately.
   - **Add Option Form**: Below each chip list, render a text input (`newDepInput` / `newTypeInput`) and an `"Add"` button (`addDropdownOption('dep' | 'type')`) to append new options safely.
2. **App Attributes Modal (`editAppMeta(appId, event)`)**:
   - Triggered by the hover pencil icon on any sidebar app.
   - Edits `App Name` (`#edAppName`), `Description` (`#edAppDesc`), and displays read-only `Last Updated (Auto)`.
3. **Timeline Date Range Modal (`openTimelineRangeModal(event)`)**:
   - Edits `Start Date` (`<input type="date">`), `End Date` (`<input type="date">`), and includes a `"Reset to Auto (Task Dates)"` button (`resetTimelineRange()`).
4. **Cell Edit Modal (`triggerCellEdit(td, appId, taskId)`)**:
   - Triggered by `ondblclick`, `oncontextmenu` (right-click), or `Enter`/`Space` keydown on any `.task-row` cell (except `index` and `appName`):
     - `task`: Text input for Description + textarea for Details.
     - `dependency` & `type`: `<select>` dropdown populated from `depOptions` or `typeOptions`.
     - `duration`: `<input type="number" min="0">`.
     - `owner`, `backup`, `checker`: Searchable team member selector (`#ownerSearch` + `#ownerList` grouped by `TEAMS_DATA` team names, highlighting the selected member with a `✓`).
     - `start`, `end`, `actualStart`, `actualEnd`: `<input type="datetime-local">` converted back to friendly `"D Mon YYYY H:MM AM/PM"` format on save.
     - `comments`, `issues`: 4-row `<textarea>`.
5. **Confirm Action Modal (`#confirmActionModal`)**:
   - Clean text-only layout (title, message, Cancel button, red Confirm button — **no SVG icon wrapper**). Used for Delete App, Clear Plan, Export JSON, and Export XLSX.

### 9. CALENDAR VIEW ENGINE (`renderCalendar`)
- Filters tasks by active date kind (`start`, `end`, `actualStart`, `actualEnd`) and search query.
- **4 Views**:
  - `day`: 24 hourly rows (`4.5rem 1fr` grid) for the selected day.
  - `week`: 7-column Mon–Sun header + 24 hourly rows.
  - `month`: Mon–Sun header + 42-day grid (`min-h-[6.5rem]` cells), showing a `.cal-badge` on dates with events, up to 3 truncated event cards (`<strong>AppName</strong>: Task`), and `+N more` overflow text.
  - `year`: 12 mini-month cards in a responsive 2/4-column grid; clicking a month name drills down to `month` view, and clicking a day number drills down to `day` view.
