User & Developer Guide

EDR MOP & Application Planner

Lightweight, zero-install, single-file planner for Enterprise Disaster Recovery (EDR) MOP execution.

Launch Planner

Quick Start / How to Use

1. Open the App

Double-click edrplanner.html in any browser (Chrome, Edge, Firefox), or run a lightweight local server like npx serve -l 8080.

2. Load Applications / MOPs

Click Add App on the left sidebar to upload an individual JSON/JS file, or click Import JSON on the top banner to load complete multi-application plans.

3. Edit Tasks & Metadata

Double-click or right-click any task cell to update details, assignees (Owner/Backup/Checker), dates, comments, or issues. Hover over sidebar apps to edit metadata.

4. Timeline, Calendar & Export

Toggle Timeline to inspect the side-by-side Gantt view, switch to Calendar for monthly/weekly schedules, and export via Export JSON or Export XLSX.

Tech Stack & Architecture Justification

Technology Role Why It Was Chosen
Vanilla HTML5 & ES6+ Core UI & Logic Runs directly in any browser with zero installation, build tools, bundlers, or package manager requirements. Instant handoff.
Tailwind CSS (CDN) Design System Enterprise styling with dark/light mode, clean responsive typography, and consistent spacing without CSS build pipelines.
SheetJS (xlsx) Excel Export Client-side .xlsx generation creating structured workbooks with a dedicated sheet for every application.
Lucide Icons Iconography Clean, lightweight SVG icons rendered on-demand without external icon font files or CSS icon sprite bloat.
Browser localStorage Persistence Persists apps, custom dropdowns, freeze states, column visibility, and theme between page reloads with zero server database needed.

Core Features

  • Side-by-Side Dual View: 75% interactive table aligned 1:1 with a 25% hourly Gantt timeline.
  • EDR Hierarchy: Pre-structured Failover and Failback phases with sub-phases and collapse toggles.
  • Unified Inline Cell Editor: Double-click / right-click edit modal with searchable team member pickers.
  • Sticky Column Freezing: Pinned columns with calculated offsets and header context toggle menu.
  • Multi-Day Timeline: Custom date ranges with sticky horizontal date headers and gradient duration bars.

Views & Modals Included

  • Table Workspace: Primary planning grid with 15 data columns and side-by-side Gantt view.
  • Calendar Container: Full scheduling engine supporting Year, Month, Week, and Day drill-downs.
  • Upload / Import Modal: Handles single-app MOP JSON files as well as multi-app exported bundles.
  • Settings Modal: Live management of custom Dependency and Task Type chips with hover-delete.
  • App Metadata & Confirm Modals: App attribute editing and safety verification dialogs.
